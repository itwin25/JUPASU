# Jupasu(주파수) 빌드 및 배포 가이드

본 문서는 Jupasu 프로젝트의 소스 코드를 클론한 후, 운영 환경에 빌드 및 배포하기 위한 상세 절차를 정리한 포팅 매뉴얼입니다.

---

## 1. 개발 및 운영 환경 (Software Stack)

서비스 구동을 위해 필요한 주요 소프트웨어 제품 및 버전 정보입니다.

| 구분 | 제품명 | 버전 | 비고 |
| :--- | :--- | :--- | :--- |
| **JVM** | OpenJDK (Temurin) | 21 | Backend(Spring Boot) 실행 |
| **Web Server** | Nginx | 1.27 (Mainline) | 리버스 프록시 및 정적 파일 서빙 |
| **WAS (Java)** | Spring Boot Embedded Tomcat | 4.0.3 | Backend API 서버 |
| **WAS (Python)** | Uvicorn / FastAPI | 0.115+ / 3.12 | AI 서비스 서버 |
| **Database** | PostgreSQL (with pgvector) | 18 | 벡터 검색 및 메인 데이터 저장 |
| **Cache** | Redis | 7.4 (Alpine) | 세션 및 캐시 관리 |
| **Node.js** | Node.js | 20.x 이상 | Frontend(Next.js) 빌드 |
| **AI Runtime** | NVIDIA CUDA (권장) | 12.x 이상 | OCR 및 AI 에이전트 가속 |

## 2. 빌드 및 환경 변수 설정 (Build & Environment Variables)

각 모듈별로 필요한 환경 변수(`.env`) 설정 및 빌드 절차입니다.

### [공통] 루트 디렉토리 `.env`
프로젝트 루트에 `.env` 파일을 생성하고 아래 항목을 정의합니다. (Docker Compose에서 공통 사용)
* `POSTGRES_DB`: 데이터베이스 이름 (예: `jupasu`)
* `POSTGRES_USER`: DB 접속 계정
* `POSTGRES_PASSWORD`: DB 접속 비밀번호
* `JWT_SECRET`: 인증용 보안 키 (Base64 권장)
* `MAIL_USERNAME`: 알림용 메일 계정
* `MAIL_PASSWORD`: 메일 앱 비밀번호

### [AI] `ai/.env`
AI 서비스 구동을 위한 전용 설정입니다.
* `GMS_API_KEY`: 임베딩 생성을 위한 GMS API 키
* `VLLM_API_URL`: (선택) vLLM 서버 주소
* `GEMINI_API_KEY`: (선택) Google Gemini 하이브리드 모드 사용 시 필요

### [Build & Deploy 절차]
본 프로젝트는 Docker Hub를 사용하지 않고 로컬에서 직접 빌드하여 배포합니다.
1. **AI 모델 다운로드**: 빌드 전 OCR 모델 파일을 미리 확보해야 합니다.
   ```bash
   cd ai
   python scripts/download_ocr_v5_models.py
   ```
2. **서비스 빌드 및 실행**: 프로젝트 루트에서 아래 명령어를 실행합니다.
   ```bash
   # 모든 서비스 빌드 및 백그라운드 실행
   docker compose -f docker-compose.port.yml up -d --build
   ```

## 3. 배포 시 특이사항 (Deployment Notes)

배포 과정에서 반드시 확인해야 할 기술적 특이사항입니다.

1. **PGVector 확장 활성화**: DB 컨테이너 실행 후, 벡터 검색을 위해 반드시 PostgreSQL에서 확장을 활성화해야 합니다.
   ```sql
   CREATE EXTENSION IF NOT EXISTS vector;
   ```
2. **GPU 가속 설정**: AI 서비스(`ai`)는 고성능 OCR 처리를 위해 GPU 사용을 권장합니다. Docker 배포 시 `docker-compose.port.yml`의 `deploy: resources: reservations: devices` 설정을 확인하십시오.
3. **임베딩 데이터 초기화**: 최초 배포 시 `back/scripts`의 임베딩 생성 스크립트를 실행하여 와인 데이터의 벡터화를 완료해야 추천 기능이 정상 동작합니다.
4. **이미지 저장소 볼륨 마운트**: 와인 라벨 및 이미지 처리를 위해 호스트 서버의 특정 경로(`/home/ubuntu/data`)가 컨테이너와 올바르게 마운트되어 있는지 확인하십시오.
5. **Nginx 및 SSL 설정**: 발급받은 **HTTPS 인증서 경로와 도메인 명**에 따라 `./nginx/nginx.conf` 파일의 `server_name` 및 `ssl_certificate` 관련 설정을 반드시 수정해야 합니다.

## 4. 주요 계정 정보 및 설정 파일 목록 (Key Config Files)

보안 및 인프라 설정이 정의된 주요 파일들의 위치입니다.

| 파일 경로 | 설명 | 주요 내용 |
| :--- | :--- | :--- |
| `docker-compose.port.yml` | 로컬 빌드용 통합 설정 | 서비스 빌드(context), 볼륨 마운트, 네트워크 |
| `back/src/main/resources/application.yml` | Spring Boot 설정 | 프로파일 설정, JPA, Redis 연결 정보 |
| `ai/app/core/config.py` | AI 서비스 설정 | API 엔드포인트, 모델 경로, 로깅 설정 |
| `front/next.config.mjs` | Frontend 설정 | API Base URL, PWA 설정 |
| `.env` (Root/AI/Front) | 환경 변수 파일 | **[보안 주의]** DB 계정, API 키, 비밀키 등 |
| `nginx/nginx.conf` | 웹 서버 설정 | 도메인 연결, SSL 설정, API 라우팅 |
| `Jenkinsfile` | CI/CD 설정 | 배포 자동화 파이프라인 정의 |
