# 🍷 와인 라벨 OCR 모바일 웹 최적화 보고서

본 문서는 대용량 딥러닝 모델을 모바일 웹 환경에서 구동하기 위해 수행한 모델 구조 최적화 및 브라우저 런타임 최적화 과정을 기록합니다.

## 1. 모델 구조적 최적화 (Structural Optimization)

ONNX 변환 이후, 웹 브라우저의 제한된 연산 환경과 WebGPU 백엔드의 특성을 고려하여 모델의 내부 구조를 수동으로 튜닝하였습니다.

- **ONNX Simplify 적용:** 변환된 ONNX 모델에 Simplify 엔진을 적용하여 불필요한 중복 연산과 정적 상수를 정리함으로써 **전체 연산 노드의 약 80%를 압축**함. 이를 통해 추론 그래프를 단순화하고 초기 세션 생성 부하를 획기적으로 낮춤.
- **WebGPU 호환성 튜닝:** WebGPU 실행 프로바이더(Execution Provider)에서 지원하지 않거나 오작동을 일으키는 특정 연산 노드들을 식별하여 제거 또는 가벼운 연산자로 대체함.
- **로그 기반 연산자 수동 수정 (`Ceil` 제거):** 실행 로그 및 프로파일링 결과를 분석하여 특정 환경에서 호환성 이슈를 일으키는 **`Ceil` 연산 노드를 직접 제거**하여 실행 안정성을 확보함.

## 2. 실행 환경 최적화 (Runtime Environment)

브라우저의 메인 스레드 점유를 방지하고 사용자 인터랙션을 매끄럽게 유지하기 위한 최적화입니다.

- **Web Worker를 통한 연산 격리:** `ocr.worker.ts`를 구현하여 무거운 ONNX 추론 연산을 백그라운드 스레드로 분리함. 모델 로딩 및 텍스트 인식 중에도 UI가 멈추지 않는(Non-blocking) 쾌적한 UX 구현.
- **Transferable Objects 활용:** 메인 스레드와 워커 간에 대용량 이미지 데이터를 주고받을 때, 메모리 복사(Copy) 대신 **소유권 이전(Transfer)** 방식을 사용하여 메모리 오버헤드와 통신 지연을 제로화함.

## 3. 데이터 로딩 및 캐싱 (Storage Optimization)

대용량 모델 파일의 네트워크 다운로드 횟수를 최소화하고 즉각적인 실행을 지원하기 위한 전략입니다.

- **IndexedDB 기반 모델 캐싱:** `src/utils/model-cache.ts`를 구현하여 한 번 로드된 모델 파일을 브라우저 내부에 영구 저장함.
- **Blob 방식 저장 방식:** 80MB 이상의 대용량 이진 데이터를 효율적으로 관리하기 위해 `Blob` 형태로 IndexedDB에 저장하여 데이터 무결성을 높이고 로딩 성능을 최적화함.
- **성과:** 캐시 적용 후 모델 로딩 시간을 **24초에서 약 3초 내외로 단축 (약 87% 성능 향상)**.

## 4. 최종 결과

- **구동 환경:** 데스크탑(Chrome WebGPU), 모바일(iOS Safari WASM/GPU) 대응 완료.
- **안정성:** 구조적 최적화를 통해 아이폰 등 메모리 제한 환경에서 탭 크래시 방지 및 안정적인 텍스트 추출 성공.
