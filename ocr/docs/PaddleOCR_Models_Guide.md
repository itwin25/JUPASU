# 🚀 PaddleOCR 모델 가이드 (v5 & VL & Structure)

Hugging Face 공식 PaddlePaddle 레포지토리의 핵심 모델군 비교 정리입니다.

## 1. PP-OCRv5 (Standard OCR)
**전통적인 고성능 OCR의 최신 버전**

*   **목적**: 이미지 내의 모든 텍스트를 가장 빠르고 정확하게 추출
*   **구조**: Detection (글자 위치) + Recognition (글자 읽기) 2단계 파이프라인
*   **특징**: 
    *   v4 대비 작은 글자 및 휘어진 글자 인식 성능 대폭 향상
    *   **Server 버전**: 고사양 서버용, 정확도 극대화
    *   **Mobile 버전**: 모바일/엣지 디바이스용, 속도와 경량화 중심
*   **추천 용도**: 영수증, 간판, 스캔 문서의 단순 텍스트 추출

## 2. PaddleOCR-VL & VL-1.5 (Multimodal / VQA)
**이미지 이해와 추론이 가능한 시각-언어 모델**

*   **목적**: 이미지를 보고 대화하거나 복합적인 질문에 답변
*   **구조**: Vision Encoder + LLM (Large Language Model)
*   **특징**:
    *   단순 텍스트 추출을 넘어 이미지의 '의미'를 파악
    *   **VL-1.5**: 최신 버전으로, 고해상도 대응 및 추론 성능 강화
*   **추천 용도**: "이 문서에서 총 금액이 얼마야?", "이 표의 두 번째 줄 내용은 뭐야?" 등 대화형 질의응답(VQA)

## 3. PP-StructureV3 (Document Analysis)
**문서 구조 분석 및 표 인식 특화**

*   **목적**: 복잡한 문서의 레이아웃을 파악하고 데이터를 구조화
*   **구조**: Layout Analysis + Table Recognition + Doc Reconstruction
*   **특징**:
    *   표(Table)를 인식하여 Excel/HTML로 복원하는 능력이 탁월
    *   제목, 본문, 그림, 표 등 문서 구성 요소를 자동으로 분류
*   **추천 용도**: 보고서 PDF를 마크다운/워드로 변환, 표 데이터 정형화 추출
